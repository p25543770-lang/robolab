# Полигон 1 — как скачать и что делает программа

## 0. Самое простое: одна команда (Windows)

PowerShell (Win + X → «Терминал»), вставить и нажать Enter:

```powershell
irm https://raw.githubusercontent.com/p25543770-lang/robolab/main/install.ps1 | iex
```

Дальше скрипт сам скачает проект, а на вопрос «Залить на робота и запустить
сейчас? [Y/n]» нажмите **Enter** — он зальёт `robot.py` на кирпич и запустит
его. Пароль кирпича — `maker`. Ответ `n` — только скачать файлы.

## 1. Скачать код вручную

**Вариант А — один файл (самый простой):**

https://github.com/p25543770-lang/robolab/blob/main/robot.py

На странице нажмите кнопку **«Raw»** (или ⤓ *Download raw file*) — сохранится
файл `robot.py`. Больше ничего не нужно: вся программа в одном файле.

Прямая ссылка на скачивание файла:

```
https://raw.githubusercontent.com/p25543770-lang/robolab/main/robot.py
```

**Вариант Б — весь проект архивом:**

```
https://github.com/p25543770-lang/robolab/archive/refs/heads/main.zip
```

Там же `README.md` (подробная инструкция) и `tools/sim.py` (симулятор для
проверки на компьютере), `polygon1.gif` (анимация прогона).

**Вариант В — обновиться прямо на роботе (без компьютера):**

В начале `robot.py` поменяйте `MODE = 'run'` на `MODE = 'update'` и запустите
программу. Она сама скачает свежий `robot.py` из ветки **main**, проверит его
и заменит себя; старая версия останется как `robot.py.old`. Потом верните
`MODE = 'run'`.

Только проверить, не меняя файл (не на роботе, а на компьютере):

```
python3 robot.py --update-check
```

Если `raw.githubusercontent.com` не открывается, программа берёт zip-архив
ветки с `github.com` — результат тот же.

Строка в логе `already the newest version` — у вас последняя версия;
`update IS available` — на GitHub лежит новее.

## 2. Что программа делает — по шагам

| Шаг | Что происходит |
|---|---|
| 0 | Робот стоит в зелёной зоне старта A |
| 1 | Два коротких писка — готов |
| 2 | **Едет прямо 50 см** (одометрия по моторам, с учётом редуктора 2:1) |
| 3 | Включает **ведение по линии**: датчики 1 (левый) и 2 (правый) снизу, простой П-регулятор, в поворотах притормаживает |
| 4 | **Ультразвук 3** смотрит вперёд. Если объект ближе **250 мм** — останавливается и пищит 3 раза |
| 5 | Если линия потерялась (оба датчика видят белое) — не падает в ошибку, а **ползёт по дуге**, пока не найдёт линию |
| 6 | Если линию не нашёл за 6 с — останавливается и пищит 2 раза |

Всё остальное время — едет по линии и следит за объектом.

## 3. Порты (проверьте перед запуском)

| Что | Порт |
|---|---|
| Левый датчик отражённого света | **1** |
| Правый датчик отражённого света | **2** |
| Ультразвук вперёд | **3** |
| Левое колесо | **C** (в программе реверс) |
| Правое колесо | **B** |

## 4. Как залить и запустить

1. Открыть [code.pybricks.com](https://code.pybricks.com), выбрать **EV3**.
2. Подключить кирпич по USB (при первом разе — *Install Pybricks Firmware*).
3. Вставить содержимое `robot.py` (или открыть файл) → **Run**.

### Сначала — проверка датчиков

В конце файла есть режим проверки: запустите программу с `--check`
(в Pybricks: допишите в конце файла строку `check_sensors()` и запустите).

На экране будет:

```
S1=  8  S2= 85   S3= 320 мм   путь=0 мм
```

* чёрная линия под датчиком → 0–20;
* белое поле → 70–95;
* ультразвук: 250–1200 мм (рука перед «глазами» → число падает);
* `путь` — прокатите робота руками 50 см по полу, должно стать ≈ 500 мм
  (если 250 — поставьте `gear_ratio = 1.0`, если 1000 — `gear_ratio = 4.0`).

## 5. Что подкрутить, если поедет не так

| Симптом | Параметр в `Settings` |
|---|---|
| виляет по линии | `kp` уменьшить (1.0–1.3) |
| улетает в повороте | `kp` увеличить (2.2–2.8), `cruise_mm_s` уменьшить |
| крутится на месте на старте | `left_motor_reversed` переключить |
| проезжает не 50 см, а 25 | `gear_ratio = 1.0` |
| рано/поздно тормозит перед объектом | `stop_mm` (сейчас 250 мм) |
| слишком быстрый/медленный | `cruise_mm_s`, `start_speed_mm_s` |

## 6. Проверка без робота

```
python3 tools/sim.py                # прогон на компьютере
python3 tools/sim.py --animate      # собрать polygon1.gif
```

Последний результат: **144/144** прогонов останавливаются перед объектом,
отклонение от линии ≤ 15 мм, время 8.6–14.6 с.

Сейчас робот останавливается перед объектом. Следующий шаг — **объезд**:
отойти в сторону, пропустить/обогнать помеху, вернуться на линию и доехать
