# Запуск по F5 в Visual Studio Code

В репозитории уже лежит готовая настройка: `.vscode/launch.json`.
Ниже — что поставить и что нажать.

## 1. Что установить (один раз)

**В VS Code:**

1. Скачайте и установите [Visual Studio Code](https://code.visualstudio.com/).
2. Откройте папку проекта: **File → Open Folder** → выберите `robolab`.
3. Поставьте расширение **Python** (`ms-python.python`).
   VS Code сам предложит его установить — справа внизу всплывёт
   «рекомендуемое расширение». Или: `Ctrl+Shift+X` → найдите `Python`.

**В терминале** (`Ctrl+~` в VS Code, слева должно быть `python`):

```
pip install pybricksdev
```

`pybricksdev` — это официальная утилита Pybricks: она компилирует
`robot.py` под EV3, заливает его на кирпич и запускает.

## 2. Что должно быть на роботе

- Прошивка **Pybricks** на EV3 (ставится с [code.pybricks.com](https://code.pybricks.com):
  *Install Pybricks Firmware*).
- EV3 подключён к компьютеру **USB-кабелем**.
- Порт EV3 виден компьютеру (на Windows — «устройство подключено»,
  на Linux — появился `/dev/ttyACM*`).

## 3. Запуск по F5

1. Откройте файл **`robot.py`** (обязательно его — F5 запускает
   выбранную конфигурацию, а в ней указан путь к `robot.py`).
2. Нажмите **F5**.
3. Внизу, на синей полосе статуса, выберите конфигурацию:
   **«EV3: залить и запустить (robot.py)»**.
4. В терминале пойдёт:

```
Searching for EV3...
Downloading robot.py...
Starting program...
```

5. Робот пискнет 2 раза и поедет. Терминал будет печатать его вывод
   (`редуктор 2:1 ... на 500 мм ...`).

Остановить: **Shift+F5**.

## 4. Что есть в `.vscode/launch.json`

| Название в списке F5 | Что делает |
|---|---|
| **EV3: залить и запустить (robot.py)** | компилирует, заливает по USB, запускает и ждёт окончания |
| EV3: залить и запустить (без ожидания) | то же, но сразу отключается (`--no-wait`) |
| Компьютер: симулятор полигона | гоняет `tools/sim.py` на ПК (робот не нужен) |
| Компьютер: стресс-тест линии | гоняет `tools/stress.py` — 261 сценарий |

## 5. Частые проблемы

| Симптом | Что делать |
|---|---|
| `Pybricks Hub not found` | EV3 не в режиме Pybricks, или кабель в другом порту. Переподключите, проверьте `pip install pybricksdev` |
| `ModuleNotFoundError: pybricksdev` | терминал VS Code смотрит в другой Python. Выполните `python -m pip install pybricksdev` тем же интерпретатором, что выбран внизу окна |
| F5 предлагает «Debug Python File» | в списке конфигураций выберите именно **«EV3: ...»**, а не автогенерённую |
| `файл robot.py не найден` | открывайте папку `robolab` целиком (File → Open Folder), а не отдельный файл |
| Программа заливается, но робот молчит | нажмите центральную кнопку на кирпиче после старта программы, либо поставьте `--start` (по умолчанию включён) |

## 6. Проверка датчиков через F5

В начале `robot.py` есть:

```python
MODE = 'run'      # 'run' — поехали, 'check' — проверка датчиков
```

Поставьте `MODE = 'check'`, нажмите **F5** — робот ничего не поедет,
а в терминале побегут строки:

```
S1=  8  S2= 85   S3= 320 мм   путь=0 мм
```

Проверили — верните `MODE = 'run'`.

## 7. Если хочется без F5

Тот же запуск одной командой в терминале (из папки `robolab`):

```
pybricksdev run usb robot.py
```

Или прямо в веб-IDE [code.pybricks.com](https://code.pybricks.com) —
там кнопка **Run** делает то же самое, только без VS Code.
