# Visual Studio Code — что нажимать

> Программа **сама обновляется на кирпиче**. Залить `robot.py` на EV3 нужно
> **один раз** — дальше при каждом запуске он проверяет GitHub, скачивает
> свежую версию и сразу едет уже новым кодом. Отдельные скрипты, SSH и
> `pybricksdev` больше не нужны.

## 1. Что установить (один раз)

1. [Visual Studio Code](https://code.visualstudio.com/).
2. **File → Open Folder** → папка `robolabs2` (где лежит `robot.py`).
3. Расширение **Python** (`ms-python.python`) — если ещё нет.

## 2. Запуск по F5

Откройте `robot.py` и нажмите **F5** → выберите:

| Конфигурация | Что делает |
|---|---|
| **robot.py (запуск на компьютере)** | просто запускает файл; на ПК программа не падает, а печатает подсказку про симулятор |
| **robot.py: проверить, есть ли обновление** | `--update-check`: печатает `this is the newest version` или `update IS available`, файл не меняет |
| **robot.py: обновить файл с GitHub** | `--update`: скачивает свежий `robot.py` и заменяет файл (старый → `robot.py.old`) |
| Компьютер: симулятор полигона | `tools/sim.py` — прогон на ПК, робот не нужен |
| Компьютер: стресс-тест линии | `tools/stress.py` — 261 сценарий |

**Важно:** F5 запускает программу на компьютере, а не на роботе. На кирпиче
её запускает `brickrun` — там же она и обновляется сама.

## 3. Как обновляется кирпич

```
brickrun --directory="/home/robot/robolabs2" "/home/robot/robolabs2/robot.py"
```

В начале заезда в терминале:

```
update: checking GitHub (robolab, branch main) ...
update: UPDATED to the newest version (1144 -> 1150 lines)
update: starting the new version now
```

Нет сети — через пару секунд:

```
update: no answer from GitHub (no network?) - driving the current version
```

и робот едет на том, что есть. Проверка идёт не чаще раза в 30 минут
(файл-отметка `robot.check` рядом с программой).

## 4. Настройки обновления (в начале `robot.py`)

| Строка | Значение |
|---|---|
| `AUTO_UPDATE_AT_START = True` | обновляться при каждом запуске; `False` — не трогать файл |
| `AUTO_UPDATE_QUIET = True` | печатать только результат; `False` — подробный лог |
| `AUTO_UPDATE_BRANCH = ''` | `''` = ветка из адреса, с которого скачали файл, иначе `main` |
| `MODE = 'update'` | обновиться и выйти, без заезда |

## 5. Проверка датчиков

В начале файла поставьте `MODE = 'check'`, запустите на кирпиче. Моторы не
крутятся, печатаются показания:

```
S1=  8  S2= 85  S3= 320 mm  S4= 900 mm  travel=0 mm
```

* рука у левого датчика — меняется `S1`;
* у правого — `S2`;
* перед «глазами» — `S3` (мм уменьшаются);
* справа — `S4`;
* `travel` — прокатите робота руками 50 см: должно стать ≈ 500 мм.

Проверили — верните `MODE = 'run'`.

## 6. Частые проблемы

| Симптом | Что делать |
|---|---|
| `usb.core.NoBackendError: No backend available` | это осталось от старого `launch.json` с `pybricksdev`. Возьмите новый `.vscode/launch.json` из репозитория (или удалите старую конфигурацию) |
| `update: no answer from GitHub` | у кирпича нет интернета. Робот всё равно поедет; обновиться можно позже |
| `update: downloaded file has a syntax error` | на GitHub лежит битая версия — файл не тронут, едем на текущей |
| `update: folder ... is read-only` | `robot.py` лежит в папке без права записи; положите в `/home/robot` |
| Хочу вернуть прошлую версию | переименуйте `robot.py.old` в `robot.py` |
| Робот стоит и молчит | смотрите лог: обновление не должно длиться дольше ~6 секунд, потом начинается заезд |
