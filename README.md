# robolab — полигон 1 «Следование по линии с движущимся препятствием»

Робот: **LEGO Mindstorms EV3** (Pybricks / EV3 MicroPython).
Первая версия программы специально простая и понятная:

1. **Старт** — едет **прямо 50 см** (выезжает из зелёной зоны A).
2. **Дальше ведёт по линии** — два датчика отражённого света снизу,
   простой П-регулятор.
3. **Увидел объект впереди** (ультразвук) — **останавливается** и пищит.

## Раскладка робота

| Что | Порт | Куда |
|---|---|---|
| **ЛЕВЫЙ** датчик отражённого света | **1** | снизу |
| **ПРАВЫЙ** датчик отражённого света | **2** | снизу |
| Ультразвук (расстояние вперёд) | **3** | вперёд |
| **ЛЕВОЕ** колесо | **C** | мотор стоит зеркально → в программе **реверс** |
| **ПРАВОЕ** колесо | **B** | — |

**Редуктор 2:1** на обоих колёсах: маленькая шестерня на моторе, большая —
на колесе. Мотор делает 2 оборота, колесо 1. Это уже учтено в программе
(`gear_ratio = 2.0`), поэтому «50 см» отсчитываются правильно.

Из-за редуктора мотору нужно крутиться вдвое быстрее: 200 мм/с по полу —
это ~680 °/с на моторе, а предел EV3 — 950 °/с. Поэтому в программе стоит
`motor_max_dps = 950`, а крейсерская скорость выбрана 200 мм/с
(≈ 230 мм/с — уже предел железа).

```
                 перед
        ┌───────────────────────┐
        │  [1] линия    [2]     │
        │        [3]  УЗ        │
  [C]   │        EV3            │   [B]
 левое  │                       │  правое
 колесо │                       │  колесо
        └───────────────────────┘
```

## Как залить на EV3

1. Откройте [code.pybricks.com](https://code.pybricks.com), выберите EV3.
2. Подключите кирпич по USB, при необходимости прошейте Pybricks
   (*Install Pybricks Firmware*).
3. Откройте файл `robot.py` (весь код в одном файле — ничего
   дополнительно копировать не надо) и нажмите **Run**.

### Сначала проверьте датчики

Запустите с флагом проверки:

```
robot.py --check
```

Моторы при этом **не крутятся**, на экране видны показания:

```
S1=  8  S2= 85   S3= 320 мм
```

* рука у **левого** датчика — меняется **S1**;
* у **правого** — **S2**;
* перед «глазами» — **S3** (мм уменьшаются);
* на чёрной линии S1/S2 около 0–15, на белом поле 70–95.

## Что подкрутить под своего робота

Всё в классе `Settings` в начале `robot.py`:

| Параметр | Зачем |
|---|---|
| `axle_track_mm` | **измерьте линейкой** расстояние между центрами колёс (по умолчанию 150) |
| `wheel_diameter_mm` | диаметр колеса, у больших колёс EV3 — 56 |
| `gear_ratio` | передаточное число: 2.0 = редуктор 2:1 (мотор → колесо), 1.0 = без редуктора |
| `left_motor_reversed` | `True` — левый мотор крутится в обратную сторону (так у вас) |
| `start_straight_mm` | сколько проехать прямо на старте (500 мм = 50 см) |
| `cruise_mm_s` | крейсерская скорость по линии (200 мм/с — безопасно для редуктора 2:1) |
| `motor_max_dps` | предел оборотов мотора, °/с (у EV3 — 950) |
| `kp` | «резкость» руления: виляет — уменьшить, не успевает в поворотах — увеличить |
| `black_ref`, `white_ref` | калибровка датчиков света (0 = чёрное, 100 = белое) |
| `stop_mm` | на каком расстоянии считать, что впереди объект (по умолчанию 250 мм) |

Если робот **крутится на месте** вместо «прямо» — переключите
`left_motor_reversed` (или `right_motor_reversed`, если реверс нужен
правому, а не левому мотору).

Если робот проезжает **не 50 см, а 25 или 100** — проверьте `gear_ratio`:
при редукторе 2:1 должно быть `2.0`, без редуктора `1.0`.

## Если робот едет не туда

| Симптом | Что сделать |
|---|---|
| виляет по линии | уменьшить `kp` (например 1.0) и добавить `kd = 0.1` |
| улетает с линии в повороте | увеличить `kp` до 2.2–2.8, уменьшить `cruise_mm_s` |
| останавливается на прямой | проверить `black_ref`/`white_ref` — датчик видит «белое» там, где линия |
| рулит в обратную сторону | поменять местами порты датчиков 1 и 2 |
| не видит объект | уменьшить `stop_mm` или проверить порт 3 |

## Проверка на компьютере

```
python3 tools/sim.py                # прогон: старт → линия → стоп перед объектом
python3 tools/sim.py --render out.png
python3 tools/sim.py --animate      # polygon1.gif
```

Результат последнего прогона (144 сценария: 6 сидов × 6 положений объекта ×
4 скорости): **144/144 остановок перед объектом**, отклонение от линии
не больше 15 мм, время 8.6–14.6 с.
